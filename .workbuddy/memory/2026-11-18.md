- `XRHeadPoseFollower` 的 GUID `ce7e61ced7ab456488f905c52a2a0fa9` 在全项目只在自身 .meta 出现，**场景与预制体零挂载**；`SpatialMeasureManager` 也从未引用它。实际生效的是主相机上的 `TrackedPoseDriver`，走 `<XRHMD>` 单例路径，而 CHANGELOG 已记录该路径在 Quest Link 下不更新 → 相机姿态不随头转。
